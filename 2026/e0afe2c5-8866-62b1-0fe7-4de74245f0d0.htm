Parameters

pointId  ObjectId
The ObjectId of the point you want to set the LabelStyleId property for.
styleId  ObjectId
The ObjectId of the style you want to set LabelStyleId to (object type LabelStyle).

Return Value

ObjectId
If the method succeeds, it returns the same ObjectId pointId passed in. If the method fails, it returns ObjectId.Null.
