Remarks
Some properties in UI are not exposed in the API because they are readonly and should be set in other places. These include: Drawing Unit displays the linear units that are used in the model space of the drawing. Set this value on the Units And Zone tab of the Drawing Settings dialog box. Drawing Scale displays the intended plot scale. Set this value on the Units And Zone tab of this dialog box. Scale Inserted Objects displays whether objects are scaled when they are inserted from other drawings. Set this value on the Units And Zone tab of this dialog box. Independent Layer On has the same effect as the Immediate And Independent Layer On/Off Control Of Display Components setting on the Object Layers tab.
