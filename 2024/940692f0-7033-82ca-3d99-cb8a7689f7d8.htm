Parameters

pointId  ObjectId
The ObjectId of the point you want to set the elevation for.
elevation  Double
The new elevation value. Specify Double.NaN to unset the elevation.

Return Value

ObjectId
If the method succeeds, it returns the same ObjectId pointId passed in. If the method fails, it returns ObjectId.Null.
Remarks
If you want to set the elevation to the state of "Has not beet set" for the CogoPoint, set the elevation to Double.NaN.
