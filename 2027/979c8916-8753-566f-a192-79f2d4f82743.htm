Remarks

This property returns an object id pointing to the referenced Profile object.

The referenced Profile object must be also referenced by the referenced Alignment object.

But if it is a feature line based corridor, it will return NULL, meanwhile throws an exception whose description is "This operation on feature line based offset baseline is invalid".
