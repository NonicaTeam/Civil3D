DataShortcutsCreateProjectFolder Method

Overload List
 NameDescription
CreateProjectFolder(String, Boolean) Create a project folder with the given name. If the current project is set, please manually right-click "Refresh" under the "Data Shortcuts" node in C3D's "Prospector".
CreateProjectFolder(String, String, Boolean) Create a project folder with the given name and description. If the current project is set, please manually right-click "Refresh" under the "Data Shortcuts" node in C3D's "Prospector".
CreateProjectFolder(String, String, String, Boolean) Create a project folder with the given name, description, and template path. If the current project is set, please manually right-click "Refresh" under the "Data Shortcuts" node in C3D's "Prospector".
