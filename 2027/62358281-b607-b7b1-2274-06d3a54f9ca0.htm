Remarks

Settings-node resolution is based on the runtime type of sourceObject.

The settings node is resolved from sourceObject using the following order:

  • Objects of type Entity, CogoPoint, and PointGroup, including objects derived from these types, use their object-specific settings node.
  • Objects of type PointDescriptionKey, CogoPointCollection, and PointGroupCollection, including objects derived from these types, use point global settings.
  • If sourceObject already references a settings node object, that node is used directly.
  • Any other DBObject falls back to the drawing root settings node.
