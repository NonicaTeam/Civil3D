WallBreaklineCreationData Fields

The WallBreaklineCreationData type exposes the following members.

Fields
 NameDescription
Elevation Specifies the elevation for all vertices.
IsRightSideOffset Specifies the surface offset side. If the value is true, then the surface on the right side of the breakline is offset by the corresponding elevation in the elevations array. If the value is false, then the surface on the left side is offset. "Left" and "right" are the directions as you walk the breakline from the start to the end.
SourceId The ObjectId of the entity to create the breakline from.
