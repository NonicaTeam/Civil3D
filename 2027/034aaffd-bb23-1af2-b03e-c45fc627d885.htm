FrequencyAlongSpirals Gets or sets the value to specify the assembly insertion frequency along the spiral portion of an alignment.
FrequencyAlongTangents Gets or sets the value to specify the assembly insertion frequency along the tangent portion of an alignment.
FrequencyAlongTargetCurves Gets or sets the value to specify the assembly insertion frequency along the curve portion of offset target.
MODAlongCurves Gets or sets the value to specify the alignment curve MOD value for assembly insertion.
